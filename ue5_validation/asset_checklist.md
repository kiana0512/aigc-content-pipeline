## A. Visual Readability

### A1. Subject Clarity
- [ ] The main subject is immediately recognizable
- [ ] The composition is not visually confusing
- [ ] The silhouette is clear enough
- [ ] Important design elements are not lost in clutter

### A2. Style Quality
- [ ] The overall style looks coherent
- [ ] The rendering quality is acceptable for reference usage
- [ ] The output is not obviously broken or distorted
- [ ] The result is visually stable enough for reuse

---

## B. Task-Specific Checks

### B1. Character Concept
- [ ] Character design is readable
- [ ] Outfit structure is understandable
- [ ] Accessories / details support the intended identity
- [ ] The design is useful as a concept reference
- [ ] The image helps communicate visual direction

### B2. UI Icon
- [ ] Icon is readable at small scale
- [ ] Shape language is clear
- [ ] Foreground/background separation is good
- [ ] The icon looks suitable for game UI ideation
- [ ] The icon is easy to distinguish from other icon concepts

### B3. Stylized Concept Art
- [ ] The image communicates a clear mood or theme
- [ ] Style direction is useful for discussion
- [ ] Composition is acceptable for reference usage
- [ ] The image helps align visual expectations

- [ ] Useful as style reference
