# UE5 Validation

## Purpose

This folder is used to record downstream validation notes for generated assets in UE5-related usage scenarios.

The goal is not to claim that generated images can directly replace final production assets.  
Instead, this module evaluates whether the outputs are useful in practical game development workflows, such as:

- concept reference
- style exploration
- UI direction support
- visual communication between design and development
- early-stage asset ideation

---

## Validation Scope

At the current stage, UE5-side validation mainly focuses on the following asset categories:

### 1. Character Concepts
Check whether generated character concept images are useful as:
- visual references for design iteration
- silhouette / costume direction references
- mood or style alignment references

### 2. UI Icons
Check whether generated UI icons are useful as:
- early-stage icon ideation references
- visual style references
- readability and shape-language exploration references

### 3. Stylized Concept Art
Check whether generated concept art is useful as:
- visual direction references
- art-style discussion materials
- scene or atmosphere ideation references

---

## Validation Principles

Generated outputs are evaluated from practical downstream perspectives, including:

- whether the subject is readable
- whether the style is consistent enough
- whether the image is useful as a reference
- whether the output is stable across multiple generations
- whether the result aligns with a target game-art direction
- whether it can reduce early-stage iteration cost

---

## What to Record

For each validation attempt, it is recommended to record:

- asset type
- workflow/config used
- prompt or subject used
- whether the output is usable as-is
- whether the output is useful as concept reference
- what is visually strong
- what is visually weak
- what should be improved next
